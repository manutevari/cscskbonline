# CSCSKB WordPress Preview

Open `cscskb-wordpress-homepage-preview.html` in a browser to review the proposed WordPress homepage before applying it to the live `cscskb.online` theme.

This preview shows:

- Official CSC headline marquee placement.
- Hero section and primary calls to action.
- Service, AI assistant, review, and map cards.
- Original review content and the supplied Google Maps directions URL.
- Responsive behavior for desktop and mobile planning.

No live WordPress theme files are changed by this preview.
